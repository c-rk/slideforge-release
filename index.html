SlideForge — About & Privacy

Your Data & Privacy

Everything stays in your browser. Slides are autosaved only to this tab's session storage. Nothing is uploaded, there are no accounts, no cookies, no tracking.

Once this tab closes, all data is erased. To keep your work, use Save JSON (re-open it here later) or Export HTML (a self-contained presentation file — math and the default font are built in, so it presents fully offline).

Quick Start
  • Pick a tool (T text, R rectangle, E ellipse, L line) and drag on the slide. Works with touch too.
  • Toolbar “Add Slide” offers layout templates (title, two-column, quote…).
  • Double-click text to edit it. Double-click math to edit the LaTeX.
  • M inserts Math/LaTeX, I inserts an image. Ctrl+V also pastes images — screenshots, image files, or an image copied off a web page.
  • Select several elements and press Ctrl+G to group them.
  • Right panel: position, colors, per-element animations, per-slide transitions.
  • F5 presents; swipe or arrow keys navigate. N notes, P presenter view.
  • Print / PDF button exports a PDF via the browser print dialog.
  • Export PNG button saves the current slide — or every slide — as an image, with a quality slider (1× slide size up to 6× for print or zoom).
  • Full shortcut list: “Shortcuts” button, bottom-right.
Saving & Reopening

Save JSON downloads your deck as an editable file — open it again anytime with the Open button. Export HTML downloads a standalone slideshow (works offline, double-click to present, ☰ opens presenter view). Large or small decks both fine — it all runs locally in your browser.
